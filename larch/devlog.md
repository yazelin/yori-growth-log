# 《優理的圖文日記》上架了：數位學徒優理每天寫一篇的圖文日記

優理是 Mori 家族的年輕數位學徒，想成為圖文作家。他的日記從 2026 年 6 月 3 日開始寫，每天一篇，配一張插畫或一則四格漫畫。現在這本日記也搬到 Larch 上了，做成一本可以翻的手帳，每天自動多一頁：

[《優理的圖文日記》](https://larch.ink/games/yaze/26a2d0f4-cffe-44f3-a321-7801a45f4759)

做法跟《格莉奇日記》是同一套，差別在優理的日記從 9 月 25 日起每一篇都是四格漫畫。整張四格放進畫面會太小，所以這次多做了一件事：日記講到哪一格，就放大哪一格。

![](https://yazelin.github.io/yori-growth-log/larch/devlog/01-title.webp)

## 怎麼看

![](https://yazelin.github.io/yori-growth-log/larch/devlog/02-calendar.webp)

- 標題畫面是一本綠皮燙金的書。翻開日記是那個月的月曆：左頁放選到那天的插畫，右頁是月曆格子。
- 點一天，再按「翻開這一天」，翻到那天的日記頁。文字一句一句出現，旁邊的優理跟著換表情。
- 四格漫畫的日子，講到哪一格就放大哪一格，左下角的小方格標出現在是第幾格。講到四格裡沒畫的事（心得、小規則），就回到整張。
- 讀完回到月曆。上個月、下個月在書的左右兩側，鍵盤左右鍵也能翻。
- 月曆上虛線框的日子，是那天的日記沒有產生出來。7 月 7 日到 9 月 2 日中間停了一段，所以沒有 8 月。
- 讀過的日子，那天的插畫會收進標題畫面的「插畫收藏」。現在一共 96 張，一開始全部上鎖。

![](https://yazelin.github.io/yori-growth-log/larch/devlog/03-page.webp)

## 用了哪些東西

整部作品沒有在 Larch 編輯器裡手動排過卡，全部是程式每天產生、同步上去的：

- 網站日記：GitHub Actions 每天跑一次。先搜尋當天的新聞找靈感，再用 deepseek-v4.1-flash 寫稿，四格漫畫由自架的生圖服務畫。
- 日記拆成台詞：照標點切成一句一句，不改寫。
- 挑格子與表情：每一句請 deepseek-v4.1-flash 看著那天的四格漫畫，挑這句在講第幾格、優理是什麼表情。結果存起來，之後不會再問一次。拿筆畫畫的動作只在句子真的寫到畫畫時才用，一篇最多一次。
- 標題斷行：日記頁左欄只放得下六個字左右。每個新標題請模型決定在哪裡換行，接回去要跟原標題一字不差才採用，不然照標點自己斷。
- 日記頁背景：用 Python 的 Pillow 畫，四格漫畫的每一格各畫一張放大版，現在一共 252 張。
- 介面：書封、紙條、攤開的手帳、日記內頁和標題畫面的封面，都是生圖做的素材。標題畫面和對話框用 Larch 的自訂介面，月曆是一張小遊戲卡。
- 同步到 Larch：跟《格莉奇日記》共用同一支同步程式，用 Larch 的 Agent API。每個月一張白板，每張白板算一個雜湊值，跟 Larch 上不一樣才覆寫，所以重跑不會多出卡片。
- 圖都放在 GitHub Pages，不上傳到 Larch。
- 上架：每晚有新日記就自動重新上架，版號是日期，例如 v26.11.04。

## 做的時候

記下幾個坑，給同樣用 Agent API 做作品的人：

- 進到一張卡片時，播放器用的是卡片本身的背景，第一句自己設的背景不會生效。所以卡片的背景要設成跟第一句一樣。
- 舞台上排第一個的立繪才算主角，其他會被調暗。優理手上那盞燈的光暈是另一張圖，要排在他後面。
- 直式手機上，畫面縮放用預設值會把日記頁切掉一半，四格漫畫只剩半張。改成 contain 才看得到整頁，代價是畫面比較小。
- 用 Agent API 讀專案設定（/settings）時，回傳的內容不包含自訂介面。要更新介面，得從整份專案讀現在的版本，不然每次都會回 409。
- 用 REST 上架時，AI 使用揭露的欄位叫 aiUsage，跟 MCP 工具的 aiDisclosure 不一樣。送錯會回 400，作品不會發布出去。
- 素材推上 GitHub 之後，要等 Pages 部署好再同步。不然卡片指到的新背景會有一兩分鐘讀不到。
- 也比過 jsDelivr：這個 repo 太大，超過 jsDelivr 的 50 MB 上限，24 次裡有 4 次回 403，所以圖都留在 GitHub Pages。

## 還在觀察的地方

功能都用沒登入的瀏覽器點過一遍，但有幾件事要跑過幾天才知道：

- 每晚自動上架：今晚會是第一次自己上架。優理每一篇都有插畫，所以每次更新都會通知追蹤的人，太吵的話再調整。
- 播放器右下角的快捷列會壓到優理的鞋子，插畫收藏頁還是 Larch 內建的樣式，直式手機的畫面偏小。這三件已經問了 Larch 官方，等回覆。

有哪裡怪怪的，歡迎留言告訴我。
