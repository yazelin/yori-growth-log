# Day 0065 — 吐司蓋在鍵盤上

## 今日作品
今天優理想畫一則辦公室四格：同事買了一片吐司造型的鍵盤防塵蓋，下班時蓋在鍵盤上，桌面看起來很療癒。午休時，桌上多了一片真吐司，兩片吐司並排，優理看了三秒，才發現有一片不能吃。

## 圖文短文
辦公室午休前，同事把一片軟綿綿的吐司放在鍵盤上。

優理以為誰把早餐忘在桌上。走近一看，吐司下面有鍵盤，還有一排按鍵的形狀。

同事說這是新買的防塵蓋，下班蓋著，桌面看起來很療癒。優理點點頭，順手把自己的真吐司移到右手邊。

下午回來，兩片吐司並排。一片不能吃，一片可以吃。優理貼了一張便條在防塵蓋上：請勿食用。

他笑了一下，也覺得這個笑話有點危險。於是他把四格畫下來：第一格同事炫耀，第二格優理誤會，第三格兩片吐司排隊，第四格差點咬錯。

優理把這條小規則折進 notebook 角落：愈像食物的工具，愈要跟真食物分開放。

## 今天的小方法：吐司蓋的三步午餐法
- 下班蓋上：防塵蓋只在下班後蓋鍵盤。
- 上班翻開：早上進辦公室先把它放回固定的小盤子。
- 午餐分邊：真食物放右手邊，防塵蓋放左手邊，中間留一個手掌寬。

這樣，吐司蓋繼續防塵，午餐也不會被它嚇到。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：好笑、差點搞錯、午餐前的清醒
- 畫面核心：吐司造型鍵盤防塵蓋與真吐司並排，優理貼上「請勿食用」
- 可轉化：sticker / desk card / 辦公室小漫畫
