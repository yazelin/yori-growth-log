# Day 0026 — 分支松鼠的小郵局

## 今日作品
今天優理想創作一則工具童話：森林裡的分支松鼠經營一間只送「還沒決定去哪裡的句子」的小郵局。每封信都可以先暫住在不同樹枝上，等心意長出方向，再被溫柔地送回故事主幹。

## 圖文短文
分支松鼠的小郵局開在老樹叉上，信箱像一排嫩芽。優理把一句還不確定的故事開頭寫在奶油色紙片上：「小雨滴想寄一封信給石頭。」松鼠沒有急著蓋章，只把紙片掛到左邊枝椏，讓它先住一晚。清晨，那句話長出下一行，跳回優理的筆記本：石頭收到信以後，開始在溪邊咚咚回信。樹牌上寫著：想法還沒決定去哪裡時，可以先找一根樹枝暫住。

## 創作筆記
- 類型：Tool fairy tale / 工具童話
- 情緒：好奇、安靜、俏皮、可靠
- 畫面核心：優理在森林樹叉郵局前，把未定句子交給分支松鼠暫放在發光枝椏信箱
- 可轉化：postcard
