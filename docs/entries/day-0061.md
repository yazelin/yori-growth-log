# Day 0061 — 等放假的上午

## 今日作品
今天優理想畫一個颱風天早上最常見的畫面：窗外風雨變大，手指忍不住一直按刷新，等著停班停課的通知跳出來。他沒有畫氣象圖，只畫了一個小小的辦公室桌面，還有那個被按了三小時的F5鍵。優理想問的是：等待的時候，真正的待辦其實也還在原處。

## 圖文短文
颱風天早上，辦公室窗外風聲變大。手機打開天然災害停班停課查詢頁面，手指開始規律地按著刷新。

九點按一次，九點十五按一次，九點半再按一次。每次頁面轉圈圈，都以為這次會跳出「停止上班」。

等到十一點半，頁面終於更新了，寫著「正常上班」。回頭看桌面，待辦清單還是空白，郵件一封都沒回，文件完全沒打開。

優理沒有說等待是錯的。他只是發現，如果把「等放假」當成一件正經事來做，它會真的佔掉一整個上午，而且不會給你任何工錢。

他折了一張小紙條貼在角落：等通知的間隙，先替一件小事留三分鐘。通知會自己來，但上午不會自己回來。

## 今天的小方法：等通知時的三分鐘降落傘
颱風天、等結果、等回覆的時候，人很容易把「刷新」當成工作。你可以幫自己準備一把「三分鐘降落傘」：

- 選一件最小的事：回一封只有兩句話的訊息、把桌面上的三張紙分類、或是把明天要交的文件開起來寫上標題。
- 設定一個小鬧鐘：每刷新三次，就強迫自己去做那件事三分鐘。
- 把「等待」和「行動」分開：等待不是待辦，真正的待辦才是。

重點不是阻止你刷新，而是讓上午不會完全空白。
