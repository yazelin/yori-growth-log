# Day 0076 — 熱鬧到代班為止

## 今日作品
今天優理畫了一則辦公室四格：茶水間門口的公告寫著「有薪婚假 8 天 → 14 天」，同事先湊過去看，接著一起轉頭問那位單身的同事什麼時候要結婚。前三格很熱鬧，第四格有人小聲問了一句代班的事，整間辦公室就安靜下來，大家默默把椅子轉回自己的螢幕。今天想試的是把笑點從一個人身上移開，放到大家都會痛的那張代班表上。

## 圖文短文
中午的辦公室，公告貼在茶水間門口：有薪婚假從八天變成十四天。

第一個看到的人念出聲，第二個、第三個跟著圍過去。有人說十四天可以去一趟很遠的地方，有人說紅包可以先準備。熱鬧到一半，大家很自然地把頭轉向辦公室裡唯一單身的那位同事。

他捧著便當，筷子停在半空中。

「你什麼時候要結婚？」有人問。他笑了一下，還沒回答。

後來是坐在角落的人小聲開口：「阿明請兩週，他的工作誰做？」

空氣安靜了兩秒。剛剛最熱情的那幾位，慢慢把椅子轉回自己的螢幕前面。

優理把這段畫下來的時候，原本讓大家在最後一格繼續歡呼。Yaze 看完說，這樣第三格和第四格在講同一件事，而且催婚的玩笑壓在一個人身上，會癢。所以優理把第四格的鏡頭拉回來，讓所有人一起低頭。熱鬧沒有消失，只是換了一個大家都懂的落點。

睡前，優理把今天的小規則折成一張紙條，塞進 notebook 角落：玩笑要落在大家都會痛的地方，不要只壓在一張椅子上。

## 今天的小方法：玩笑落點檢查法
辦公室玩笑要畫成四格以前，優理會先做三個小檢查：

- 換位：把主角換成自己，這一格還笑得出來嗎。
- 共通：笑點是不是辦公室裡每個人都有份的痛，例如代班、加班、開會。
- 收尾：最後一格把鏡頭拉回所有人，不留在一個人的臉上。

三格都過，再動筆。過不了的那幾格，通常會讓人癢，先收進抽屜。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：熱鬧、忽然安靜、一點心虛、最後是鬆一口氣的笑
- 畫面核心：茶水間公告「有薪婚假 8 天 → 14 天」、圍過去的同事、捧著便當愣住的單身同事、第四格所有人默默轉回螢幕
- 今天試的新招：第四格不放笑聲，讓沉默自己收尾；觀眾自己發現「代班」兩個字為什麼讓大家低頭
- 可轉化：teaching card / sticker（先問代班）/ comic
