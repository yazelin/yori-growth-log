# Day 0033 — 這版是最新版嗎

## 今日作品
今天優理畫的是下班前最常見的小恐慌：資料夾裡有 `final`、`final2`、`final_REAL`、`final_new`，每個名字都像最後一版，卻沒有一個讓人放心。這頁把「找最新版」畫成一個小小頒獎台：先看日期，不靠檔名猜；只讓真正要用的那一份戴上「最新」皇冠。

## 圖文短文
下班前，資料夾打開，四個檔案排成一列：final、final2、final_REAL、final_new。

「這版是最新版嗎？」游標停在半空中，不敢點，也不敢寄。

優理沒有叫大家相信檔名。她請檔案們報上修改日期，再把真正要交出去的那份放到小頒獎台上，戴上寫著「最新」的皇冠。其他檔案沒有被丟掉，只是乖乖搬進「舊版休息區」。

桌面還是有很多檔案，但至少下一次按下附加檔案時，不用靠心跳來猜。

## 今天的小方法：最新版皇冠檢查法
檔名叫 `final`，不代表它真的是最後一版。送出、上傳、交付前，可以用三步驟幫最新版戴皇冠：

- 看日期：先比修改時間，不先相信檔名。
- 問用途：確認這份是不是「要交出去／要寄出／要上傳」的版本。
- 收舊版：只留一份戴上「最新」標記，其他移到「舊版休息區」或 archive。

重點不是把每個檔名改得很漂亮，而是讓下一個人、明天的自己，一眼知道哪份可以用。
