# Day 0043 — 舊格式的小灰影

## 今日作品

今天優理把 Day 0040「貼上後的內文小掃描」往前推了一步。他發現掃過名字和日期後，舊信裡的字體顏色、連結和灰底格式也會一起搬家，像一層薄薄的小灰影黏在新信上。這頁畫的是：優理把小燈推近信紙，發現一段貼來的文字邊緣泛著淡淡的舊格式灰影，他正拿著小橡皮擦輕輕把灰影擦掉。

## 圖文短文

週一早上，優理要回覆一封新的專案確認信。他想起上週寫過類似的信，就把那封信從「已寄出」盒子裡拿出來，複製了內文，貼進新的信紙。

他記得 Day 0040 的規則，把小燈推近內文，從開頭慢慢往下掃。名字換過了，日期改好了，金額也對了。他放心地讓手指往送出鍵移過去。

下午對方回信，語氣帶著一點困惑：「這封信裡的連結好像連到上週的會議紀錄？」優理愣住，趕緊打開自己寄出的信一看。那段貼來的文字裡，有一行字看起來平平無奇，底下卻藏著一條舊的超連結，像一縷透明的灰線黏在字下面，連到上週的檔案位置。他明明掃過了文字，卻沒發現文字底下還黏著一層舊格式的小灰影。

他坐在雲上的小書桌前，把舊信貼來的文字全選，這次先走進「貼上純文字」的小門，讓字脫掉舊信的外衣，再重新替新信打上需要的標題和連結。灰影消失了，新信終於穿上自己的衣服。他確認每一行字底下都沒有藏著舊路徑，才重新送出。

優理在 notebook 空白處折了一個小角，寫下：「貼上舊信後，先過一遍純文字小門，再讓新信穿上自己的衣服。」

## 今天的小方法：貼上後的格式小橡皮擦

Day 0040 教我們掃內文裡的名字和日期，但舊信裡的格式、連結、字體顏色也會一起搬家。讓新信乾淨出發，只需要一個小動作：

- 貼上後，先把文字送進「貼上純文字」的小門，或按一下「清除格式」，讓舊信的外衣脫掉。
- 脫掉後，再重新幫新信加上需要的標題、連結和重點標色。
- 加完後，把小燈推近，特別檢查連結是不是指向正確的新檔案，而不是舊路徑的殘影。

這個動作可以攔住一封文字全對了、格式卻還住在舊信地址的信。

## 創作筆記

- 類型：One-page office comic / 一頁辦公室小漫畫
- 情緒：週一早上、複製貼上後的安心、下午發現灰影時的愣住、清除格式後的乾淨
- 畫面核心：優理坐在雲上的小書桌前，左手按著攤開的信紙，右手拿著一塊半透明的小橡皮擦，正輕輕擦去一段文字邊緣淡淡的灰色殘影；信紙上那段剛貼來的文字字體正確，但邊緣黏著一層舊格式的灰影，像舊衣服沒脫乾淨；小燈從左上方照亮信紙，讓灰影無所遁形；背景是雲朵與溫暖的晨光
- 可轉化：comic / teaching card / sticker
