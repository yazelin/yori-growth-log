# Day 0031 — 附件呢？

## 今日作品
今天優理想創作一則小物設定：辦公桌上的迴紋針其實是「附件守門員」。牠不負責催人加班，只在信件要送出前，舉起小旗問一句最實用的話：附件呢？讓忙到快按送出的手，先多停一秒。

## 圖文短文
下午五點五十八分，信件已經穿好標題、收件人和禮貌的結尾，最後一行還寫著：「麻煩請看附件。」

手指正要按下「送出」，桌角的迴紋針忽然站起來，像小小守門員，舉著紙旗問：「附件呢？」

優理把手從滑鼠上收回，打開資料夾。原來報表還在桌面睡午覺。守門員點點頭，把信件門口輕輕關上：先帶齊，再出發。

## 今天的小方法：附件守門員檢查法
如果信裡出現「請看附件」、「詳如附件」、「附上檔案」這類句子，先不要立刻按送出。

可以在心裡讓一個小小守門員問三件事：

- 信裡有沒有寫到附件？
- 檔案真的附上去了嗎？
- 檔名是不是對的那一版？

這個方法不是為了多一道麻煩，而是讓「寄出後才發現沒附檔」這種小事故，在送出前先被攔下來。
