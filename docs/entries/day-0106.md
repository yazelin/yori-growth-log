# Day 0106 — 倒數五分鐘的茶

## 今日作品
今天優理畫的是一杯下午三點的熱茶。第一格，阿凱把一個小小的智慧倒數杯墊放到鍵盤旁邊，興奮地舉手機給優理看，時鐘指著三點，優理手上還捏著茶包，阿凱說：「研究說放空五分鐘多22％。」第二格，杯墊在小馬克杯下面亮出5：00，阿凱用一根手指按下開始，優理看著那個數字，眉毛動了一下。第三格，時鐘走到三點四分，杯墊只剩0：01，茶還冒著厚厚的蒸氣，兩個人都湊近看倒數。第四格，畫面停在杯墊響完的那一刻，優理把杯子拿起來，阿凱愣住。

## 圖文短文
下午三點，辦公室的時鐘剛好走到整點。優理手裡捏著茶包，還沒放進杯子，阿凱已經把一個小杯墊擺到鍵盤旁邊，手機螢幕湊過來，說研究講放空五分鐘可以多22％。優理看著那個亮亮的數字，先注意到杯墊邊緣有一圈很小的指示燈，亮著。

阿凱用一根手指按下5：00，熱氣從馬克杯口慢慢升上來。優理本來想先喝一口，手伸到一半又縮回來，因為茶還燙，杯緣也霧霧的。他看著倒數從4：59往下跳，覺得這五分鐘大概不會真的拿來放空。

三點四分，杯墊只剩0：01，兩個人都往前湊。茶沒有被動過，蒸氣反而更厚，阿凱的指尖還停在杯墊旁邊。優理盯著那個1，差點伸手把杯子移開，最後只是把茶包放進杯裡，等聲音響完。三點五分，杯墊嗶了一聲，優理把杯子舉起來，吹了吹，說：「只夠等茶涼。」阿凱愣在原來的姿勢。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：下午的疲倦、好奇、好笑、差一步就能喝
- 畫面核心：智慧倒數杯墊、冒煙的茶、阿凱與優理一起等倒數，最後優理吹茶
