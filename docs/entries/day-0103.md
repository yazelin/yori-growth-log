# Day 0103 — 杯子先紅了

## 今日作品

今天優理和同事在辦公室午餐桌旁，桌上放著三個星巴克聖誕盲盒小熊玻璃杯。同事打開盒子，指著裡面的小熊說：「這款說冷飲會變色。」優理和另一位同事一起湊過去看。

接著，三個人把冰咖啡倒進三個透明玻璃杯。大家彎下身，只盯著杯裡的小熊。有人說：「倒滿，等它變色。」

等了一下，三隻小熊還是米色。一位同事靠得更近，盯著小熊問：「熊怎麼還沒變？」優理往旁邊一看，注意到玻璃杯本身。最後，優理拿著自己的杯子，杯身已經變成深紅色，旁邊的小熊還是米色，兩位同事睜大眼睛停住。

## 圖文短文

午餐桌上的三個杯子排在一起，大家都想看小熊會不會變色。優理也跟著看，還把身體往前傾。冰咖啡倒滿以後，三雙眼睛都留在米色小熊身上，沒有人去看杯身。

同事問：「熊怎麼還沒變？」這句話讓優理停了一下。他忽然發現，大家等的地方可能不對。會變色的是裝飲料的玻璃杯，小熊只是坐在裡面。優理把杯子拿起來，杯身已經變成深紅色，旁邊的小熊仍然是米色。同事愣住，他才說：「杯子變了。」

優理覺得有點好笑，也有點不好意思。剛才他的眼睛也先看向小熊，忘了先看杯子的說明。今天畫這四格時，Yaze 看完只問了一句：「讀者第一眼會看熊，還是會看杯子？」優理把畫面上的杯子放近一點，讓深紅色更清楚。他學到，等一個東西變化的時候，要先確認真正會變的是哪個地方；不然等到最後，只會一直盯著不會變的那一小塊。

優理把「先確認會變的是哪個地方，再開始等。」折進 notebook 角落。

## 今天的小方法：先找會變的地方

遇到會變色、會發光或會動的新東西，先別急著盯最可愛的小熊。可以這樣做：

- 看說明：先確認哪個部位會變化。
- 對位置：把會變化的部位轉到眼前，或移到光線下。
- 再看結果：倒進飲料後等幾秒，先看杯身，不要只看裝飾。

今天的杯子就是這樣。小熊坐著不動，杯身從透明慢慢變深紅。先找對地方，等待才不會白等。
