# Day 0102 — 遙控器上的雪花

## 今日作品

今天優理畫的是早上剛進辦公室的那一幕。同事縮著肩膀走進來，手機上亮著十五度，說：「新聞說今天十五度。」過一會，那位同事套上厚羽絨外套，另一個同事把圍巾往上拉，兩個人都還在發抖，優理從桌上抬起頭看他們。

接著優理從桌邊拿起冷氣遙控器，螢幕那面朝著自己，兩個包得緊緊的同事一起望過來，問他：「你要開暖氣嗎？」

最後畫面停在優理的拇指上。他按下去的那一顆是關機，遙控器的螢幕亮著，後面的同事表情空白，牆上冷氣的出風口慢慢停住。

## 圖文短文

早上九點，辦公室的門一開，同事縮著肩膀走進來，把手機舉得高高的：「新聞說今天十五度。」他把手機收進口袋，過沒多久就套上羽絨外套。隔壁那位把圍巾拉到鼻子下面，兩個人都還在抖。

優理看著他們，心裡想，外面十五度，室內怎麼會更冷。他伸手從桌邊拿起冷氣遙控器，兩個包得緊緊的同事一起看過來，問他是不是要開暖氣。

優理按下按鍵的時候，其實沒看清楚螢幕上寫什麼。牆上的冷氣「嗶」一聲，出風口的葉片慢慢合起來，風停了。同事的表情停在半空中，其中一個說：「蛤？」

他把遙控器翻過來，螢幕上寫著十五度，旁邊還有一個雪花圖示。這台冷氣從早上就開著，一直在送冷風，房間裡的十五度是它自己吹出來的。優理把螢幕轉給同事看，自己也笑了一下，說了聲抱歉。

他把遙控器放回桌上，螢幕朝上，又撕了一張小紙條貼在旁邊，紙條上寫著：先看它現在在做什麼。然後他把這句話折進 notebook 角落：先看機器現在在做什麼，再決定要開還是要關。

## 今天的小方法：遙控器三秒檢查法

覺得冷或熱的時候，手很容易先去找按鍵。按下去以前，可以先花三秒鐘：

- 轉正螢幕：把遙控器翻過來，看清楚現在是什麼模式、設定幾度。
- 看風有沒有在吹：出風口有風、有聲音，機器就已經在工作了。
- 再按按鍵：確定要開、要關，還是要換模式，再按下去。

這三秒不會耽誤什麼，但會讓人知道自己按下的那一顆，到底會讓房間變冷還是變暖。
