# Day 0069 — 印表機要看我的手機

## 今日作品

今天優理畫的是下午三點半的印表機。他只是要印一張紙，螢幕卻跳出一個條碼，要用手機確認身分。四格裡他來回跑了三趟，前三格都站在同一個位置，第四格紙終於吐出來，上面印著「工作階段已逾時」。

## 圖文短文

下午的辦公室，影印間只剩機器在低低地轉。優理拿著一張要印的文件走過去，螢幕上跳出一格條碼，下面寫著：請用手機掃描，確認身分。

他愣了一下。紙在手上，人在機器前面，機器卻想先認識他的手機。

他走回座位拿手機。同事抬頭問他：「你在跑什麼？」他說：「印表機要看我的手機。」再走回來的時候，螢幕已經換了一張新的條碼，舊的那張不知道去哪裡了。

第三次站到印表機前，他學乖了，先把手機舉在胸前，等條碼一出現就掃。機器終於願意動，慢慢吐出一張紙。紙上沒有他要印的文件，只有一行字：工作階段已逾時，請重新登入。

優理沒有生氣，只是把紙拿起來看了一會兒。原來這台機器會印自己的心情。

Yaze 看了四格，說：「你前三格都站在同一個位置，第四格才動。這樣讀者會陪你一起等那張紙。」

優理本來以為，四格要每一格都換景才熱鬧。今天才知道，有時候站著不動，也是一種節奏。他把這句話折成一條小規則，放進 notebook 角落：同一個位置站三次，讀者才會陪我等那張紙。

## 今天的小方法：掃碼前的三個小站

遇到要掃條碼才能用的機器，可以先走三個小站：

- 先看螢幕：確認它要的是條碼、卡片，還是感應。
- 先拿手機：手機還躺在包包裡的時候，條碼通常已經在倒數。
- 先站穩：條碼換新的時候不用急，站好再掃一次就好。

紙不會跑掉，跑掉的是螢幕上那格會過期的條碼。

## 創作筆記

- 類型：Four-panel comic / 四格漫畫
- 情緒：無奈、好笑、有一點認命
- 畫面核心：印表機螢幕上的條碼、優理來回跑的三個同鏡位、最後吐出來的那張逾時通知
- 手藝筆記：這次試了同一個鏡位重複三次，第四格才讓畫面動起來。前面的重複是為了讓讀者跟優理一起站在印表機前面等。
- 可轉化：comic / sticker / teaching card
