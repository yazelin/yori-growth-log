# Day 0093 — 整理日：三張便條折成一張

## 今日作品
今天優理畫四格漫畫：整理日，他在辦公桌邊攤開一整疊便條，把寄信前的檢查規則一張一張排好。旁邊同事看著十一月行事曆哀號，整月沒有國定假日，上班日排得滿滿。優理把三張便條疊在一起，折成一句更短的話，最後只留一張貼在螢幕邊。

## 圖文短文
下午，同事把十一月行事曆貼到白板上。整月沒有國定假日，二十一個上班日像一排小石頭，大家圍著看，先嘆了一口氣。優理那時正把 notebook 攤在桌邊，便條紙從夾層裡滑出來，像一群跑太快的紙螞蟻。

他先挑出寄信前最常翻的三張。Day 0031 寫著「附件呢？」；Day 0037 提醒寄信前要認出戴皇冠的那一份檔名；Day 0055 又補上一句，信紙裡提到附件的那句話要對齊，不然內文會指向舊名字。三張便條排在一起，優理才發現它們都在講同一件事：寄出去以前，讓附件、檔名和內文互相認得。

他把三張便條疊好，用筆在空白處折出一條短規則：「寄出前，附件、檔名、內文名字三張一起對齊。」原本三張紙在桌上會互相絆倒，現在只剩一句，貼在螢幕邊剛剛好。

翻到 Day 0030 那張「先不要送出」時，優理停了一下。他本來想再抄一次，但手指已經在送出鍵前自己停住了。那條規則沒有消失，它長進手裡，變成一個很小的暫停。於是優理把那張便條放回抽屜，沒有再寫新的。

最後，他抽出一張小紙條，寫上「先撐到十二月」，貼到十一月行事曆的空白角落。那張不能折併，因為整個月都要看見。

## 今天的小方法：寄出前對齊三張便條
整理信件的便條時，可以先把重複的提醒疊在一起，留下一個三步驟：

- 附件在不在：打開附件夾，確認檔案真的跟著信走。
- 檔名對不對：看修改日期與用途，確認是今天要交出去的那一份。
- 內文有沒有叫錯名字：信裡提到附件的那一句，名字要跟檔案一樣。

三步驟都看過，再讓手指靠近送出鍵。整理讓留下來的那張真的會提醒人，也讓已經會做的事回到手上。
