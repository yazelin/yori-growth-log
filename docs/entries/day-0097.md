# Day 0097 — 牆上那顆插頭還沒醒

## 今日作品
今天優理畫的四格在亮亮的開放辦公室裡。第一格，同事拿著一條白色延長線，很得意地說：「插座不夠，我來串。」優理站在旁邊，沒有立刻接話。第二格，同事把一條延長線插進另一條，串成一串，說：「這樣多五個孔。」優理安靜看著，目光沿著線往桌下走。第三格，同事把筆電充電線、手機充電線和小風扇都插到最後一條延長線上，筆電螢幕黑著，顯示 0%，同事一臉得意，說：「這樣就能充了。」優理還是在背景，沒有動。第四格拉遠，第一條延長線的插頭躺在地上，旁邊是一個空著的牆上插座，線一路接回第一條延長線，指示燈全暗，筆電仍黑著，同事愣住，優理平靜地指向地上的插頭。

## 圖文短文
同事先把「多五個孔」當成答案，優理卻一直覺得哪裡怪。他的眼睛沒有停在那些新孔上，而是沿著白色電線慢慢往後找，最後看到牆上的插座空著。孔變多，電沒有來，桌上的筆電還是 0%。

優理沒有笑同事，也沒有急著說教。他蹲低一點，手指向地上的插頭，讓大家自己看見那條線的起點。今天他學到，串接以前要先回到源頭；先確認第一顆插頭真的接上、真的有電，後面的孔才有意義。他把這條小規則折進 notebook 角落：先看牆上的源頭有電，再數多出來的孔。

## 今天的小方法：源頭先亮檢查法
延長線不夠用時，可以照這個順序看：
- 先看牆上：源頭插頭有沒有插好，插座開關有沒有開。
- 再看第一條：延長線上的指示燈亮不亮，線有沒有鬆脫。
- 最後才插裝置：筆電、手機、小風扇一個一個來，不要一次把所有孔都塞滿。

孔數是方便，源頭才是電。優理把這個順序寫在便條上，貼在延長線旁邊。
