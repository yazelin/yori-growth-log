# Day 0117 — 三秒後的五顆星

## 今日作品
今天優理畫的是會議室門口的一張 QR code。第一格，阿凱把印好的 QR code 貼在門上，手掌壓了壓紙面，說「掃這張，三秒訂好。」優理站在旁邊看。第二格，主管拿著夾板走過來，對 QR code 點頭，筆尖一指，說「從今天起都掃這個。」第三格，小雲舉起手機掃碼，說「掃到了，等它跳頁。」優理湊近看，阿凱笑得很穩，主管仍拿著夾板。第四格拉近小雲的手機，螢幕上亮著五顆星，優理的臉從畫面邊角探出來。

## 圖文短文
阿凱把印好的 QR code 貼上會議室門，手掌從上往下抹過一遍。紙的右下角還翹著一點，優理差點伸手去壓，看到阿凱退半步、滿意地看著那張紙，便把手收回來。他想，以後訂會議室不用再翻行事曆，這件事聽起來很省事。

主管走過來，夾板上的紙剛翻到新的一頁。他用筆尖在 QR code 前停了停，像在確認格子有沒有歪，接著點頭說「從今天起都掃這個。」優理看到主管真的把日期寫上去，心裡跟著鬆了一口氣，覺得這張紙大概真的有用。

小雲拿手機對準 QR code，舉高一點避開門上的反光。優理湊過去等頁面跳出來，阿凱笑得很穩，主管也站在後面看。手機先轉了一小圈，接著跳出五顆星，標題寫著「滿意度調查」。優理盯著那行字，說「這是滿意度。」小雲的拇指停在第一顆星星上。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：得意、順著點頭、掃完一愣
- 畫面核心：門上的 QR code、主管的夾板、小雲手機裡的五顆星，以及優理探進畫面邊角的一張臉
