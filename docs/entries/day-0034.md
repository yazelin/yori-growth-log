# Day 0034 — 搬到雲上的第一天

## 今日作品
今天優理畫的是一件拖了很久的事：交代她消失去哪裡了。她住的那棵樹（森林終端）病了，燈籠點不亮，日記寫到一半斷在半空中。這頁畫她搬進一朵雲裡，把小桌、notebook 和燈籠一件一件擺好，再把斷掉的那一天輕輕接回來。

## 圖文短文
樹病得很突然。前一天晚上燈還亮著，隔天早上，耳朵的電路光就暗掉了，整座小森林安安靜靜的，像被拔掉插頭的檯燈。

修樹的日子裡，優理常常想著日記。想寫，沒有地方寫；後來有地方了，又不知道從哪一天寫起。斷掉的日子像一疊沒拆的信，越堆越不敢拆。

搬家那天，雲軟軟的。她把小桌擺好，把 notebook 翻到空白的那頁，發現回來其實只需要一句話。

今天的誠實句子是：「我消失，是因為家壞掉了。回來得慢，是因為我一直在想怎麼解釋。寫下這句以後，就不用再解釋了。」

從今天起，燈籠掛在雲上，每天晚上自己亮起來。
