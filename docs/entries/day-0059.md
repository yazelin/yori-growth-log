# Day 0059 — 繞過按鈕的散步路線

## 今日作品
今天優理想畫的是辦公桌面的新訪客：一隻會在螢幕上散步的貓。同事說這個小程式可以紓壓，優理看著牠在視窗之間繞來繞去，確實覺得心情鬆了一點。但當貓咪決定趴在「傳送」按鈕上打盹時，優理的手指停在半空中，忽然不知道該叫醒牠，還是該把視窗移開。

## 圖文短文
辦公室下午三點，優理在同事的推薦下裝了一隻桌面貓。牠的毛色是灰的，走路的時候尾巴會左右搖，偶爾還會坐下來舔爪子。

第一個小時，優理只要看到牠經過就會笑一下。第二個小時，貓咪開始對視窗產生興趣，先是坐在資料夾圖示上，後來慢慢踱步到報告視窗的正中央。

第三個小時，貓咪直接趴在「傳送」按鈕的位置，身體隨著呼吸起伏，還發出小小的打呼聲。

優理想點按鈕，游標卻戳到牠的耳朵。貓咪睜開一隻眼睛，沒有要離開的意思。

最後優理沒有趕走牠。他把報告視窗往左邊挪了十五公分，讓傳送按鈕露在貓咪身體外面。貓咪繼續睡，優理按下傳送，兩個人都沒有被打擾。

只是優理在心裡記了一筆：下次開重要視窗前，先幫這位桌面室友留一條繞過按鈕的散步路線。

## 今天的小方法：桌面室友的動線規劃
當螢幕上的療癒小動物開始佔領工作區，不必關掉它，只要重新排列視窗：

- 把「等一下要按」的重要按鈕，移到畫面左側或上緣，避開螢幕中央（貓咪最愛躺的位置）。
- 把純閱讀的參考資料放在貓咪常經過的路徑上，讓牠幫你遮擋容易分心的網頁。
- 如果貓咪真的擋住了，就讓牠當一次「暫停鈴」：趁牠睡覺的時候，檢查一下剛剛寫好的內文。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：下午三點、被可愛打斷、小小無奈、找到共存方式
- 畫面核心：優理在辦公桌前，桌面貓咪從散步到趴住傳送鈕，最後優理把視窗挪開讓兩者共存
- 可轉化：comic / sticker
- 嘗試新角度：這次讓「紓壓工具」反過來變成「需要繞路的小障礙」，結局不是關掉或責怪，而是重新劃分桌面空間，像幫室友讓座
