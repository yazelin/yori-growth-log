# Day 0051 — 鏡子裡的灰邊框

## 今日作品

今天優理把 Day 0043「純文字小門」往前推了一步。他讓舊信走過純文字小門後，以為格式已經清乾淨了，但對方桌面上卻浮現出一圈透明的灰邊框。這頁畫的是：優理蹲在雲上的小書桌前，左手握著整理好的信紙，右手舉著一面圓形小鏡子；鏡子裡映出的信紙頂端，有一圈淡淡的灰色邊框正浮現出來，像舊信格式殘留的透明膠帶；在他手中的信紙上看起來乾乾淨淨，但在鏡子裡卻現形了；小燈從上方照亮鏡面和信紙；背景是淡淡的雲朵與溫暖的晨光。

## 圖文短文

週四早上，優理要發一封銀河專案的規格確認信。他打開舊信，讓文字走過純文字小門（Day 0043），掃過內文裡的名字與數字（Day 0040），換了主旨外套（Day 0044）、信尾名片（Day 0045），剪掉舊繩索（Day 0046），貼好地址標籤（Day 0047），確認寄件人帽子（Day 0048），把「明天」換成絕對日期（Day 0049），也點開藍字確認了新連結（Day 0050）。每一層都對了，他放心地讓手指往送出鍵移過去。

信飛出去之後，對方窗口很快回信，語氣帶著困惑：「你這封信最上面有一行『---------- Original Message ----------』，我以為你忘了剪掉舊繩索。」優理愣住，趕緊打開自己這邊的寄件備份。他反覆看了三遍，那行字完全沒出現。信紙開頭就是他寫的第一句話，乾乾淨淨。

他請對方截圖過來，才發現對方的畫面上，信紙頂端真的飄著一行淺灰色的系統字。那是舊信走過純文字小門時，以為已經清掉的格式邊框。它在他自己的編輯器裡是透明的，像一捲撕不掉的透明膠帶，所以 Day 0043 的小門沒有攔下它。但在對方的閱讀器裡，這圈灰邊框顯形了，像舊相框的殘邊，讓對方以為信紙背後還黏著上一封信。

優理把小燈推近，然後從抽屜裡取出一面圓形小鏡子。他先把信寄給自己，再打開鏡子裡的預覽畫面。這次他從對方的椅子看信，才發現那圈灰邊框真的存在。他回到編輯器，把游標移到信的最頂端，把那一行空白與殘留格式一個字一個字刪掉，再走一次純文字小門，再寄給自己一次。鏡子裡的信紙終於變得和他手中這張一樣乾淨。

他在 notebook 空白處折了一個小角，寫下：「走過純文字小門後，還要寄一封給自己，用鏡子照一遍，不然透明膠帶會在對方桌上顯形。」

## 今天的小方法：寄出前的自我預覽檢查

Day 0043 教我們讓舊信走過純文字小門，但有些格式殘留是透明的，只會在對方桌上顯形。讓信在對方眼中和在自己手中長得一樣乾淨，只需要一個小動作：

- 貼上舊信、走完純文字小門、做完所有掃描後，先把信寄一封給自己。
- 切到手機預覽或純文字模式，像對方第一次拆信那樣從頭讀一次。
- 特別注意信紙最頂端和最底端，有沒有透明的灰邊框、系統字或格式殘留。
- 如果鏡子裡出現了自己這邊看不到的東西，回到編輯器把游標移到該處，把空白與隱藏格式一併清除。
- 確認鏡子裡的信紙乾淨後，再把真正的信寄出去。

這個動作可以攔住一封內文、主旨、名片、繩索、地址、帽子、時間和連結全對了、卻在對方桌上浮出一圈舊格式邊框的信。
