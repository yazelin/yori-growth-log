# Day 0101 — 香菇派贏定了以後

## 今日作品
今天的四格在辦公室茶水間。同事一手拿著香菇山，一手拿著竹筍里，說：「兩種口味我一次買齊。」桌上左邊的碗貼著「香菇山」，右邊的碗貼著「竹筍里」，優理站在旁邊看。

同事把竹筍里倒進左邊的碗，竹筍形狀的零食落進寫著「香菇山」的碗裡。右邊寫著「竹筍里」的碗，裡頭已經裝了山形狀的零食。優理瞇起眼睛，發現碗裡的食物和貼紙對不上。

同事從左邊的碗拿起一顆竹筍形狀的零食，說：「香菇派贏定了。」優理沒有出聲，眼睛在貼紙和零食之間來回，手沒有碰標籤。

最後，優理的手把兩張貼紙換了位置，左邊的碗貼上「竹筍里」，同事舉著竹筍零食愣住。

## 圖文短文
下午的茶水間桌上多出兩個小碗。同事把一包香菇山和一包竹筍里放在旁邊，說：「兩種口味我一次買齊。」左邊的碗貼著「香菇山」，右邊的碗貼著「竹筍里」。優理站在桌邊，看見同事把竹筍里倒進左邊的碗。

竹筍形狀的零食一顆一顆落進寫著「香菇山」的碗裡。右邊寫著「竹筍里」的碗，裡頭裝的卻是山形狀的零食。優理瞇起眼睛，心裡想：貼紙和碗裡的東西對不上。他沒有馬上伸手，因為同事正從左邊的碗拿起一顆竹筍形狀的零食。

「香菇派贏定了。」同事說。優理看著同事手上的竹筍，又看左邊碗上的「香菇山」貼紙。他等這句話說完，才把兩張貼紙撕起來，交換位置。左邊的碗貼上「竹筍里」，右邊的碗貼回「香菇山」。同事舉著零食愣住，眼睛睜得很大。

優理把貼紙壓平，心裡記下一句話：碗裡的東西和貼紙對不上，先等對方說完再換貼紙。他打算今晚把這句折進 notebook 角落。下次分零食時，大家伸手拿之前，應該就能先看見碗裡真正的形狀。

## 今天的小方法：先讓碗裡的東西點名
茶水間分零食，碗和貼紙很容易一忙就貼反。優理今天用的方法很簡單：
- 倒進去之前，先看包裝上的名字和碗上的貼紙是不是同一個。
- 倒完之後，再看碗裡零食的形狀，讀一次貼紙。
- 如果有人已經舉起零食準備發表意見，先讓他說完，再把貼紙換到正確的碗邊。
這樣下一個人伸手拿的時候，不用靠猜，也不用聽誰喊得比較大聲。
