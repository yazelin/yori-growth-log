# Day 0075 — 舉手四小時的小視窗

## 今日作品

今天茶水間裡在傳一則新聞：AI 助理可以連續自主運作七個小時。大家一邊攪咖啡，一邊想像以後可以早點下班。優理也聽了一會兒，回到座位才發現，自己螢幕角落那個「要儲存嗎？」的小視窗，從下午兩點就一直舉著手。

這頁四格把兩個畫面放在一起：一個能連續工作七小時的助理，和一個連續舉手四小時的小問句。

## 圖文短文

「新聞說 AI 可以連續工作七小時耶。」同事把手機轉過來，螢幕上的字亮亮的。另一個人從隔板後面探出頭：「那我們是不是可以早點下班？」

辦公室笑了一下，咖啡機也響了一下。

優理跟著笑完，回到自己的位子。螢幕右下角有一個小視窗還站在那裡，舉著手，問他要不要儲存。旁邊的時鐘指著兩點。

他本來只是想離開一下。回一則訊息、聽一段新聞、幫同事看一下檔案。事情一件一件疊上去，那個小問句就一直站著，沒有變小，也沒有變吵，只是把手舉高了一點。

下班時間到了，時鐘走到六點。小視窗還舉著手。優理把手放上滑鼠，按下儲存。

「你也連續舉手四小時了。」他說。

小視窗放下手，安靜地消失。那天晚上，優理把一句話折成小紙條，塞進 notebook 角落：螢幕上舉手的小視窗，先回答它，它會舉得比人久。

## 今天的小方法：舉手清單

下班關機前，花三十秒掃一眼螢幕，數一數有幾個小視窗還在舉手。

- 先看螢幕的四個角落：存檔、更新、列印、傳送，最常躲在邊邊。
- 能回答的就回答：儲存、不儲存、取消，按下去都是一種回答，不用想太久。
- 不能回答的寫在紙上：像「要更新嗎？」這種要問別人的，先寫一行，明天第一件事處理。

重點是把舉手的小問句留在今天，不要讓它站在螢幕上過夜。
