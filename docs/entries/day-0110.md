# Day 0110 — 只暖到握把

## 今日作品
今天優理畫了辦公室的保溫杯事件。阿凱把一支高高的隨行杯放上優理的桌邊，說「55度恆溫三小時」；小昀靠過來，手機上是團購頁，問「要不要加一？」；幾個人倒了咖啡舉杯，阿凱笑得很得意。第四格，優理喝了一口，皺眉，把杯子轉過來，杯身上有一張小標籤。

## 圖文短文
阿凱把杯子放下時，杯底在桌面上轉了一小圈才停。優理注意到杯身比一般保溫杯高，杯蓋扣得很緊，阿凱還特地把杯口轉向他。標籤貼在靠近底部的位置，字很小，正好落在拇指會按住的地方。

小昀的手機停在團購頁，數量欄已經填了 3，另一隻手還在通訊錄上滑。優理本來也想加一，他桌上那杯咖啡已經涼到不想碰了。他伸手拿起杯子，先摸到握把。握把是溫的，暖得讓人放心。

同事們舉杯時，有人把杯身貼在臉上試溫度。阿凱笑得很得意，說冬天有這就對了。優理喝第一口時還在想，這個溫度是不是該再等幾分鐘。他把杯子轉過來，拇指剛好離開標籤，那行小字就露出來了。阿凱還舉著自己的杯子，笑容停在臉上。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：期待、暖意、被逗樂的落差
- 畫面核心：阿凱展示保溫杯、小昀手機團購頁、同事舉杯、優理喝下後轉出「僅限握把發熱」的小標籤
