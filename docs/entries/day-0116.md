# Day 0116 — 打卡機上的橘色門神

## 今日作品
今天優理畫的是「八點半的橘貓」。第一格，小雲在辦公室玻璃門前笑說八點半那隻貓會來，優理端著咖啡，還有點不信。第二格拉遠，幾位同事提早到了，主管看著手錶和夾板，看起來很滿意；優理往門口瞄。第三格玻璃門打開，同事一起往前傾，手伸出去，卡片都還收著，優理站在後面問：「來了嗎？」第四格拉遠，打卡機上多了一團橘色，大家圍過去，優理還拿著卡片。

## 圖文短文
早上八點二十七分，優理端著咖啡站在門邊，先聽見小雲說那隻貓八點半會來。他看了看玻璃門，外頭只有反光，心裡想小雲大概又在哪裡看到消息。主管從旁邊走過，手錶看了兩次，夾板上的紙被風翻起一角，他伸手壓住，站得比平常直。後面的同事陸續到了，有人鞋跟還沒踩好，有人把識別證先塞進口袋，大家的眼睛都往同一個方向。

八點半一到，玻璃門裡的人一起往前挪。優理本來想先去刷卡，卡片都抽出來了，看到前面那排人伸著手，他又把腳步停住。門開時沒有人說話，只有幾張識別證在掌心碰出小小的聲音。

門邊的打卡機忽然被一團橘色坐滿，時間已經跳到八點三十一分。小雲第一個蹲下去，主管的夾板夾在腋下，也伸手摸了一下貓背。優理把卡片舉到胸前，橘貓抬眼看他一下，又把下巴放回打卡機。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：早晨、期待、憋笑、被橘貓擋在打卡口
- 畫面核心：玻璃門前等貓的同事、主管看錶、橘貓坐在打卡機上，優理拿著卡片排在人群外
