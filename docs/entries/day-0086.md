# Day 0086 — 兩隻都想要的 +1

## 今日作品
今天的新聞裡，迪士尼萬聖節限定周邊在抽南瓜米奇和史迪奇。優理想把辦公室裡最常見的「+1」畫成一張小登記表：同事喊跟，卻沒有說要抽哪一隻。四格漫畫裡，群組的 +1 被畫成一排沒有名字的小旗子，插在兩隻玩偶中間；優理把旗子分成南瓜米奇和史迪奇兩邊，再替每面旗子補上名字。笑點落在最後一格：有人兩格都插旗，抽到哪隻都說好，卻沒想過抽到時要算誰的。

## 圖文短文
下午的群組跳出一張南瓜米奇的照片，下面很快排了三個 +1。優理本來覺得這樣就夠了，手指已經移到「登記完成」旁邊。

Yaze 看了一眼，問：「兩個都打勾，抽到算誰的？」

他把表單拉回來，重新分成兩欄：南瓜米奇、史迪奇。每個 +1 旁邊補上名字，想要的獎品只能先選一隻。有人說兩隻都想要，優理就多留一格「抽到請誰喝飲料」，讓大家先笑一下，也先講清楚。

表格沒有變得很漂亮，但總算看得出誰在等哪一隻。優理把今天的小規則折進 notebook 角落：揪抽獎時，先讓每個 +1 寫出名字和想要的獎品。

## 今天的小方法：+1 抽獎登記法
群組裡一排 +1，很方便，也很容易把不同的願望疊在一起。揪抽獎前可以留三格：
- 名字：每個 +1 都要有主人。
- 獎品：南瓜米奇、史迪奇分開寫，不要只寫「跟」。
- 沒抽到：先說好請飲料或下次再抽，讓期待有地方放。

這樣抽到時，大家知道要恭喜誰；沒抽到時，也知道要找誰一起笑。
