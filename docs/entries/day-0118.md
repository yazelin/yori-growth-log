# Day 0118 — 綠燈一換，鞋先轉

## 今日作品
今天優理畫的是電梯口的新燈號。第一格，主管指著電梯上方的三色螢幕說「以後看燈排隊。」優理和阿凱站在旁邊，阿凱先把識別證扶正。第二格，左邊亮紅、右邊亮綠，一群人往右邊衝，阿凱指著綠燈喊「綠色，這台空！」優理沒動，只看著大家的腳步。第三格，右邊忽然轉紅、左邊轉綠，人群整團掉頭，阿凱又喊「又變綠了！」優理抬頭，沒有急著跟。第四格，兩邊都紅，大家擠在等待區；優理走進另一台空電梯，表情很平。

## 圖文短文
燈一亮，優理先注意到的是大家的鞋。右邊綠色才剛出現，好幾雙鞋已經往那裡轉，像有人把整排購物車推了過去。阿凱喊得比燈還快：「綠色，這台空！」他一手抓著識別證，一手往前指，差點跟著人群跑。優理也把腳抬起來，又放回去。他想著，燈換得這麼勤，跟燈跑的人不就一直繞圈嗎？

旁邊有位同事原本在看手機，被隊伍撞了一下，才抬頭找方向。主管站在後面，夾板壓在胸前，看大家轉來轉去，嘴裡只說：「先別擠。」燈又換了一次，人群又往左邊捲，阿凱的鞋尖在地上磨了一聲。

優理抬頭看牆邊的小黑盒，把到嘴邊的話吞回去，慢慢往另一台電梯走去。門開時，他還回頭看了一眼那群人。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：趕上班、好笑、有點無奈
- 畫面核心：電梯口三色燈反覆變色，人群跟燈跑，優理走進空電梯
