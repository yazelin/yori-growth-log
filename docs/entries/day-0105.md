# Day 0105 — 鴕鳥頭先試用

## 今日作品
今天優理畫的是午休前的團購小騷動。小雲拿平板問他：「要不要加一？鴕鳥午睡枕。」隔板上方卻露出一顆巨大的鴕鳥頭，阿凱的聲音從後面悶悶傳來：「隔絕九成鍵盤聲。」小雲拿團購單去戳，頭套一動也不動，優理站起來往旁邊看。最後整張桌子入畫，答案留給讀者自己看。

## 圖文短文
下午的座位區有點悶，小雲把平板轉過來，先問優理要不要加一。優理本來只看到螢幕上的鴕鳥頭套，還想說這種東西誰會買，餘光卻瞄到隔板上方多了一顆更大的鴕鳥頭。那顆頭停在那裡，像在等大家發現。

阿凱的聲音從隔板後面悶悶地傳出來，說可以隔絕九成鍵盤聲。優理皺起眉，視線往下移，看到一點深藍色帽 T 的袖子卡在頭套下面。他差點伸手去掀，想確認裡面是不是真的有人，小雲已經拿團購單走過去，一邊問「阿凱，你要不要加一？」，一邊用紙角戳了戳鴕鳥的嘴。

頭套沒有反應，小雲的團購單停在半空中。優理站起來，往旁邊挪一步，想從側面看清那顆頭是怎麼固定住的。後方一位同事端著杯子經過，腳步慢了一下，又裝作沒事繼續走。優理把手收回來，站在桌邊沒有出聲。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：午休前的悶、狐疑、憋笑
- 畫面核心：小雲的團購單、隔板上的鴕鳥頭、優理站近查看，最後整張桌子入畫
