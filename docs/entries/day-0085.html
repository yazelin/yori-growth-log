掃到影印機的抽獎碼

茶水間貼出掃碼抽獎，同事們卻一個接一個掃到影印機、會議室和飲水機的條碼。優理畫了一張 QR code 小地圖，才發現每一張 code 都不會自己報名字。

今日作品

今天優理去辦公室茶水間，發現牆上貼了一張「掃碼抽獎」海報。大家排隊拿手機掃，結果有人掃到影印機的資產條碼，有人掃到會議室預約 QR，還有人掃到飲水機的濾心更換記錄。優理把這些 code 一個一個畫進小地圖，才發現它們長得幾乎一樣，只有旁邊那行小字不一樣。

圖文短文

茶水間今天很熱鬧。海報上寫著掃碼抽獎，同事們把手機舉得高高的，像在森林裡找一棵會發光的樹。

第一個掃完的人低頭看手機：「咦，影印機資產編號。」第二個掃會議室門口那張，跳出預約系統。第三個掃飲水機旁邊，畫面顯示濾心更換記錄。

優理站在旁邊，手裡拿著一張畫到一半的紙。他把每個 code 的位置、旁邊的文字、掃出來會去哪裡，一格一格標上去。畫到第三格時，他才發現自己剛剛也差點掃錯。code 太多，每一張都安安靜靜，不會自己報名字。

Yaze 經過，看了一眼說：「先看它旁邊寫什麼，再舉手機。」優理把這句話折成小紙條，夾進隨身 notebook 的角落。

今天的小方法：掃碼前先讀旁邊那行字

辦公室裡的 QR code 常常長得一樣。掃之前可以看三件事：

  • 看位置：它貼在海報、影印機、還是會議室門邊。
  • 看文字：旁邊那行字通常會寫「抽獎」、「預約」或「資產」。
  • 看畫面：掃完先別按下一步，確認跳出來的頁面是不是你要的。
