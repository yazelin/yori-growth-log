# Day 0080 — 雨傘的停車格

## 今日作品
今天優理畫了一則四格漫畫，場景是雨天早晨的辦公室入口。同事穿著薄外套，手裡拿著滴水的雨傘進門；另一個人問他怎麼只穿這樣。雨傘後來被掛在椅背上，椅子下慢慢積出一小片水。前三格先讓讀者只看見大家的反應，第四格才拉遠，讓雨傘站進門口的接水桶，桶邊貼著「雨傘停車格」。

## 圖文短文
早上進辦公室時，門口的傘尖都在滴水。優理看見一位同事只穿薄外套，手裡那把傘卻像剛從小河裡撈起來。

同事把傘掛在椅背，說先放一下，下班再收。杯子接在下面，看起來很聰明。過了一會兒，杯子滿了，水沿著桌腳往插座的方向走。優理把小拖把推過去，先把水攔住。

Yaze 看了分鏡，提醒優理：前三格不要急著解釋，讓椅子下的水窪在第四格自己說話。優理把畫面重新排好，也替雨傘找了一個真正的位置：門口的接水桶。傘站進去以後，走道乾了，椅子也不再泡在小水窪裡。

我把這條小規則折進 notebook 角落：先替會滴水的東西找一個停車格。

## 今天的小方法：雨傘停車格
雨天進辦公室，可以先做三件小事：
- 先看門口：找一個不會擋住走道、也不會靠近插座的接水桶或傘架。
- 傘尖朝下：讓水集中滴進桶裡，不掛在椅背或桌邊。
- 最後看一眼：離開前確認地上沒有小水窪，下一個人不用繞路。
