# Day 0073 — 字幕不會笑

## 今日作品
今天優理想畫一張四格：外商同事的電話會議，耳機裡跑出即時翻譯字幕。字幕很快，一句都沒漏，卻停在畫面正中間，把對方的臉擋住一半。優理把字幕框往旁邊拖，讓那張笑臉露出來。

## 圖文短文
下午的會議室，電話擴音裡是國外同事的聲音，一句接一句，講得很快。優理的耳機跟著冒出翻譯字幕，字幕很乖，每一句都翻好了。

他一開始只盯著字幕。螢幕中間那行字說，明天中午前一定要交。他點頭，開口說今晚留下來做。

電話那頭安靜了一下。

旁邊的同事湊過來，小聲說，剛剛那句好像是隨口講的。

優理把字幕框從螢幕中間拖到角落。字幕還在，句子還是一樣的句子，但對方的臉露出來了，嘴角從頭到尾都是往上彎的。

原來那句話一直在笑。

他重新問了一次：「可以請你再說一次嗎？」對方笑著說只是開玩笑，不用加班。字幕還是很快，但現在他知道要配哪一張臉去看它。

收工前，他把一張小紙條折進 notebook 角落：字幕框往旁邊站一點，讓臉先說話。

## 今天的小方法：字幕讓位三步
即時翻譯很方便，但字幕只帶得走字，帶不走表情。電話或視訊會議裡，可以這樣用：

- 先看臉：對方開口時，先把眼睛放在他的表情和停頓上，字幕晚半秒再讀。
- 再看字：句子裡出現「應該、可能、開玩笑」這類詞，先別急著回答。
- 不確定就回問：一句「可以請你再說一次嗎」，比整晚加班便宜很多。

字幕只是幫手。留一點位置給對方的臉，翻譯才不會只剩下字。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：方便、誤會、恍然、鬆一口氣
- 畫面核心：下午的會議室、電話擴音、筆電上的即時翻譯字幕、壓在畫面正中間的字幕框、優理把字幕框拖到螢幕角落
- 今天新試的角度：讓字幕框當一次擋住臉的壞人。前幾篇的笑點多靠時機、道具或重複，這次靠「遮住」與「露出」的差別，笑點來自一張被擋住的表情。
- 可轉化：comic / sticker / teaching card
