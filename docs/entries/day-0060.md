# Day 0060 — 會議室的限量小卡

## 今日作品
今天優理想畫一個午餐後的會議室：同事們帶著剛搶到的限量小卡回到座位，會議還沒開始，小卡已經在桌上傳了一圈。優理看著那份需要傳閱的文件被壓在漢堡紙盒下面，發現真正需要排隊的東西，其實一直躺在那裡。

## 圖文短文
午餐時間的搶購潮漫進了辦公室。同事們帶著剛到手的小卡，像帶著戰利品，會議室還沒開燈，三張小卡已經在桌上輪流轉動。

「這張角度好帥。」「我跟你換這張。」手機鏡頭對準小卡，閃光燈亮個不停。

優理站在桌邊，看見那份需要三人傳閱簽名的文件，還靜靜躺在漢堡紙盒旁邊，一頁都沒翻過。

他沒有叫大家不要玩。只是伸出手，把文件往上挪了一點，讓它重新進入桌面中央。

「這份也在排隊等你們。」

同事們低頭，發現文件還沒動，而小卡已經蓋住了第一頁。有人笑著說：「糟糕，這個才是真正限量。」

優理把這個畫面折進 notebook。衝動搶到的東西會發光，但一直躺在桌上沒人翻的文件，才是真正的限量品。他寫下一條小規則：發光的東西會自己跳進眼睛，但排隊等你的文件不會。

## 今天的小方法：會議室裡的兩種限量品
午餐後的會議室常變成展示場：新買的聯名小卡、剛搶到的優惠券、熱騰騰的八卦。這些東西會自己發光，吸引所有人的手機鏡頭。但會議桌上真正需要被傳閱、簽名、確認的文件，不會發光，也不會喊叫。

進會議室後，可以用三秒鐘做一件事：先把要討論的文件放到小卡拿不到的地方——例如，每個人的手邊，而不是桌面中央的小卡堆裡。或者，在手機拿出來之前，先讓文件在桌上傳一圈。

重點不是禁止分享小卡，而是讓真正限量的事項——主管的時間、同事的注意力、今天必須決定的簽核——先被看見。
