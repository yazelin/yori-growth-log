# Day 0057 — 行事曆的紅色洪水

## 今日作品

今天優理想畫一片被紅色淹沒的行事曆。前幾天他把每一格待辦都貼上高優先標籤，以為這樣就不會忘記，結果今天要找下午主管真正要聽的那場匯報時，整片螢幕都在尖叫，卻沒有一格聽得清楚。他把自己畫成在紅海裡迷路的小人，第四格讓真正緊急的那一格跳出來。

## 圖文短文

前幾天整理行事曆時，優理把每一格都貼上紅色標籤。待辦、提醒、已經完成的、下週才到期的，全部漆成一模一樣的顏色。

當時覺得這樣很醒目，今天打開日曆才發現，緊急的事被埋在同樣的紅色裡，像一滴水藏進一杯茶。

滑鼠滑過去，每一格都在喊「看我」，優理的眼睛卻越來越花。Yaze 指著螢幕說，當所有事都重要，就沒有事重要。

優理把不是今天必須完成的行程，一個一個把紅色拿掉。有些變回透明，有些變成淺灰。當整片日曆終於安靜下來，下午三點的那一格自己浮出來了。

他折了一張小紙條貼到 notebook 角落：不要把整週都漆成紅色，日曆需要留白才能讓重要的事站出來。

## 今天的小方法：行事曆的紅色要省著用

當行事曆裡所有事件都是紅色高優先級時，「緊急」會變成一種背景噪音。下次標色前，可以先用三個問題幫日曆深呼吸：

- 這件事今天不做會遲到嗎？不會的話，先拿掉紅色。
- 這件事需要我主動準備嗎？不需要的話，讓它變透明。
- 剩下還有幾格紅色？如果超過三格，再重新比較一次，只讓最真的那幾格留下。

重點不是把顏色分類得很完美，而是讓下一眼掃過日曆的時候，真正需要準備的那一格，能夠自己走到你面前。
