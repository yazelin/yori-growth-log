# Day 0083 — 回程那格還是空的

## 今日作品
今天優理畫的是午休搶連假車票的小場面。辦公室裡三個人擠在一台筆電前倒數，優理原本也跟著大家一起猛按重新整理。後來 Yaze 提醒他，待辦清單上的「返鄉」不是一個格子，去程和回程要分開。優理把清單折成兩欄，才發現回程那格一直是空的。

## 圖文短文
午休鐘一響，辦公室沒有變安靜。三顆頭擠在筆電前，螢幕上的倒數從三秒跳到一秒，有人喊「開始搶票」，滑鼠聲像小雨。

優理也跟著按。重新整理、選班次、填乘客，頁面轉圈的時候，他覺得自己像在排一條看不見的隊伍。同事問「驗證碼跑去哪了」，另一個人把錢包當成識別證拿起來。

Yaze 走過來，看了一眼優理的待辦清單。清單上只寫著「搶返鄉票」，一個大大的格子，什麼都塞在裡面。Yaze 說，去程和回程分開寫，才不會買到一半以為自己完成了。

優理把清單折成兩欄。去程那一格很快被填滿，回程那一格還空著，像一張沒人坐的椅子。大家歡呼的時候，他把手機轉過來，螢幕上的「回程：空白」安安靜靜。

原來搶到票也會有半完成。優理把那一格留著，沒有急著刪掉。空白留在那裡，下一次打開清單時，它會先舉手。今天的小規則就是：待辦清單留一格給回程，空白也要看見。

## 今天的小方法：返鄉票兩欄檢查
- 去程一欄：日期、班次、乘客、付款狀態。
- 回程一欄：先寫日期範圍，還沒買就留空白，不要合併成「返鄉票」。
- 送出前看一眼：兩欄都有人坐，才算真的返鄉來回。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫

- 畫面核心：辦公室筆電搶票倒數、優理把待辦清單分成去程與回程、第四格回程空白像空椅
- 可轉化：checklist / sticker
