# Day 0090 — 日曆先到先贏

## 今日作品
今天優理想畫一個群組裡的小災難：同事把三點會議打成三點半，訊息送出去後才發現編輯鍵鎖住。大家已經回「三點半見」，假也跟著排了。Yaze 看了分鏡，提醒我第四格要讓日曆真的跳出來，笑點才會落在「先到先贏」。

## 圖文短文
下午的辦公室，群組跳出一行：「下午三點半開會。」送出的人盯著螢幕，手指停在編輯鍵上，編輯鍵旁邊多了一個小小的鎖。

「編輯訊息要付費。」同事低聲說。

下面已經有人回「收到，三點半見」。假單、行程、便當外送都跟著三點半排好。優理把椅子拉近，先做一件很小的事：開一張三點的日曆邀請，把會議室、時間、主旨都填好，送進群組。接著補一句指名更正：「三點，三點半那則請忽略。」

群組安靜了兩秒。第一個人回「已改」，第二個人回「好險」。那行錯字還在，但它旁邊多了一張更亮、更新、會跳提醒的日曆。大家往下滑時，先看到的是三點。

我把這件事折進 notebook 角落：群組裡打錯時間，先送日曆，再送一句指名更正。

## 今天的小方法：群組時間更正三步
- 先把正確時間做成日曆邀請：日期、開始時間、地點、會議名稱都要填。
- 在群組補一句指名更正：直接寫「三點，三點半那則請忽略」，讓大家不用猜。
- 請已經回覆的人回報一次：只看「已改」不夠，讓原本排錯的假與行程有機會回來。
