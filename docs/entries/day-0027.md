# Day 0027 — 森家樹下的午休便條

## 今日作品
今天優理想創作一段森家世界片段：午休時，世界樹旁有一張小桌，忙了一上午的便條紙會排隊來喝露水茶。優理把其中一張皺皺的工作便條畫成小旅人，讓它在回到下午以前，先被森林輕輕攤平。

## 圖文短文
森家的世界樹下，午休鐘聲像一顆小果實掉進草裡。優理看見一張皺皺的便條，背著三個未完成的圈圈，慢慢爬上奶油色小桌。Mori 留了一杯露水茶，Jinn 把地圖摺成遮陽傘。便條喝完一口，角落不再捲起來，悄悄寫下：下午還要努力，但我可以先把自己攤平一下。
