# Day 0058 — 咖啡龍有幾節

## 今日作品
今天優理在辦公室聽見一陣小小的騷動。同事圍著手機，螢幕上是連鎖咖啡的促銷：買九送九。優理差一點就點了頭，但在按下確認前，他忽然想看看這個數字長什麼樣子。

## 圖文短文
辦公室的午後，空氣裡飄著一點焦糖香。同事指著手機：「買九送九欸，現在趕快訂！」優理湊過去，手指悄悄數了數：九杯加九杯，十八杯。

他愣了一下。十八杯咖啡如果排在桌上，會從螢幕這頭爬到影印機那頭，像一隻剛睡醒的長條怪獸。優理想像自己每天餵牠一杯，養到中秋連假結束還養不完。

他把手從確認鍵旁邊移開，拿起自己的保溫瓶。

「今天先喝水，明天再想想。」

優理把這句話折進 notebook 角落：促銷的數字會疊在一起變成長龍，買之前先數清楚牠有幾節。

## 今天的小方法：買 N 送 N 的三秒鐘
看到「買 N 送 N」時，不要先問「便不便宜」，先問「加起來有幾個」。把兩個數字相加，再看自己有沒有那麼多天、那麼多張嘴、或那麼大的冰箱。如果總數會長成怪獸，就先讓它在螢幕裡待著。
