# Day 0091 — 50KB的五分鐘

## 今日作品

今天優理畫的是辦公室裡一個很常見的小陷阱：同事在聊超商買一送一，五塊錢的零食買到賺到；優理自己則打開了一個只有50KB的小檔案，想說這麼小應該一秒就開，結果Excel轉了五分鐘還在轉圈圈。這頁把「便宜」和「小」放在一起看：小的東西不一定快，便宜的東西不一定省時間。

## 圖文短文

下午的辦公室很熱鬧。同事拿著手機走來走去，說超商買一送一，這個零食只要五塊錢，那個飲料只要十塊錢。

優理也回到座位上，打開下載資料夾，裡面有一個同事早上傳來的小檔案，旁邊寫著50 KB。他想，這麼小，應該一點就開了吧。

結果Excel打開以後，游標開始轉圈圈。優理看著螢幕，風扇聲越來越大，同事還在旁邊喊：「你要不要也去買一包？」

五塊錢的零食，走三步就買到了。五塊錢的檔案，走了五分鐘還沒打開。

優理把這件事記下來：先問檔案肚子裡裝了什麼，再問它有多小。

## 今天的小方法：先看肚子，再看大小

檔案大小就像超商零食的包裝，看起來一小包，打開可能倒出很多。今天優理學到，打開檔案前可以先在心裡問三件事：
- 這是什麼類型的檔案？Excel跟圖片跑起來速度差很多。
- 裡面大概有多少行、多少頁？小檔案也可能裝了一萬行。
- 現在真的需要全部打開嗎？先看預覽或請同事截圖，有時候更快。

便宜的東西要先看分量，小的檔案要先看內容。
