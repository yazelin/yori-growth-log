# Day 0104 — 鍵盤安靜了，抽屜還沒

## 今日作品
今天優理在開放式辦公室看見同事舉著一包鍵盤墊，包裝上寫著「降40分貝！」。同事很得意，優理站在旁邊，先沒有跟著點頭。

同事把機械鍵盤放上墊子開始打字，優理把手機的分貝計靠近鍵盤。螢幕停在綠色低讀數28 dB，隔壁同事拿出耳塞，表情鬆了一口氣。

同事往後靠在椅背上，笑著說「終於安靜了。」他一邊說，一邊把手伸進抽屜。優理沒有接話，只把眼睛移到抽屜上。

最後，同事撕開一包洋芋片，手停在半空，碎屑飛起來；優理把手機分貝計對著袋子，畫面上跳出一顆紅色的數字。這一幕留給讀者看圖，優理心裡的那句話先放在下面。

## 圖文短文
辦公室下午本來只剩鍵盤聲。同事把新買的鍵盤墊舉得很高，像拿到一面可以讓大家安靜的盾牌。優理陪他試了一次，機械鍵盤在墊子上敲起來確實小聲，手機上的分貝計也亮著舒服的綠色。隔壁同事把耳塞收進口袋，像是今天終於可以少受一點罪。

同事說「終於安靜了」的時候，手伸進了抽屜。優理順著他的手看過去，心裡有一點不放心。抽屜打開後，洋芋片袋被撕開，清脆的聲音在座位間散開，碎屑也跟著跳出來。手機上的數字一下子變紅。

優理沒有說鍵盤墊不好。他把包裝上的「降40分貝」和手機上量到的聲音放在一起看：墊子讓鍵盤聲變小，抽屜裡的聲音卻沒有被一起收好。他剛剛也差點只盯著鍵盤，忘了安靜是整個位子的事。

所以優理把一張小紙條折進 notebook 角落：先問哪一種聲音被降掉，再相信安靜。下一次同事再展示新工具，他會先看工具顧到哪個聲源，再聽聽附近還有什麼會接著響。

## 今天的小方法：安靜來源檢查法
商品上的分貝數字可以幫助理解，但不能代替現場。優理把今天看到的狀況整理成三個小檢查：

- 先讀降低的是什麼聲音：包裝寫「降40分貝」，要確認它指的是鍵盤敲擊聲，還是整個辦公室的聲音。
- 再把手機分貝計放在聲源附近：用平常打字的方式試一次，看看數字和耳朵聽到的是不是同一件事。
- 最後巡一下附近：抽屜、零食袋、椅子滑輪、電話和隔壁同事，都可能是下一個聲音來源。

工具能收好一種聲音，就已經有幫上忙。要讓整個座位安靜，還要多看幾個地方。
