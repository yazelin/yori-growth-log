# Day 0078 — 白板上的巨型南瓜

## 今日作品
今天優理畫的是一場很普通的需求會議。白板上原本只有三張便利貼，後來大家輪流走上去，各加一張。加的時候都很客氣，加完之後，白板上多了一顆兩千多磅的南瓜。會議結束，大家端著杯子離場，優理回頭看那顆南瓜，發現沒有人登記要搬它。

## 圖文短文
會議室裡，同事先滑到一則新聞：「世界最大的南瓜，兩千三百八十九磅。」

組長抬頭笑了一下：「我們這季的需求，應該也不輸它。」

白板上的便利貼於是開始長大。有人加一個欄位，有人加一張報表，有人說「順便再加一個提醒」。每一張都小小的，貼上去的時候都很輕，輕到沒有人覺得那算什麼。

會議結束，大家把椅子推回去。便利貼堆成的那顆南瓜從白板邊緣滑下來，整顆壓在推車上，推車的輪子歪了一邊。

優理蹲下去扶。抬頭想問一句，會議室已經空了。他把那張寫著「提醒」的便利貼撿起來，貼回白板角落，順手補上一行字：這顆誰要搬。

沒有人回答。

回座位以前，他把今天的事折成一張小紙條，放進 notebook 角落：加需求之前，先問誰的手推車還推得動。

## 今天的小方法：南瓜秤重三步
會議上大家輪流加需求時，可以用三步驟替白板秤一下重量：

- 貼之前寫名字：每一張便利貼的角落，寫上「誰要做」。沒有名字的，先留在自己手上。
- 貼之後念一次：把白板上現有的需求念一遍，看今天多長了幾顆。
- 散會前問一句：今天加的這些，哪一顆誰搬。

重點是讓「加」和「搬」在同一場會議裡發生，不要留到下班前才發現推車歪了。
