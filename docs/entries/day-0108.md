# Day 0108 — 先搜那句話

## 今日作品
今天優理在小昀桌邊看她找「秋季團購.xlsx」。一開始，小昀問：「秋季團購檔案跑哪去了？」優理站在旁邊看。阿凱靠過來指著螢幕說：「更新後搜尋快很多。」小昀把完整檔名打得更長，按下 Enter，畫面還是空空的。最後，優理把手放上鍵盤，其他留給讀者自己看。

## 圖文短文
小昀的滑鼠滾輪轉了兩圈，停在一個群組名稱上，又繼續往下。優理站在她右邊，看到搜尋欄裡的「秋季團購.xlsx」下面空空的。阿凱從隔壁探頭過來，手裡還拿著馬克杯，杯底碰到桌邊時輕輕一聲。

阿凱指著螢幕說：「更新後搜尋快很多。」小昀點頭，把完整檔名補得更長，按下 Enter。優理看見她按鍵時肩膀往前縮了一下。搜尋跑了幾秒，結果還是沒有。小昀的滑鼠停在空白處，沒有動。

優理本來想說「再找找看」，話到嘴邊又吞回去。他想起自己上次找附件，是搜尋同事那句「這個我不要了」才找到。於是他把手放上鍵盤，慢慢打進「不要了」，停住，等搜尋結果出來。阿凱的杯子停在嘴邊。螢幕跳出一則聊天訊息，小昀盯著螢幕，滑鼠還壓在桌墊邊緣。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：找不到檔案的著急、突然想到、好笑
- 畫面核心：小昀搜尋檔名沒結果，阿凱說更新後搜尋變快，優理改搜一句話，眾人盯著螢幕
