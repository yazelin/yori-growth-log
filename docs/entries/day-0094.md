# Day 0094 — 水桶先當垃圾桶

## 今日作品
今天優理想畫一張停水前的小慌張：新聞說十二個縣市要分區停水，最長十八小時。辦公室裡大家先問「你家有水桶嗎」，優理才發現自己只有一個馬克杯。下班後他抱回一個藍色水桶，結果被室友當成垃圾桶。停水當天，房東傳來一句「頂樓水塔已滿」，那個水桶只好真的去當垃圾桶。

## 圖文短文
午休時，同事把手機推過來，螢幕上寫著分區停水。優理盯著自己的馬克杯，忽然覺得它太小了。

五金行的藍色水桶排成一排，店員說今天水桶賣得比雨傘好。優理抱了一個回家，標籤還沒撕，室友就問：「你買垃圾桶怎麼沒加蓋？」優理把水桶放到浴室門口，心裡想，明天它會很重要。

停水當天，房東在群組裡說頂樓水塔已經補滿，今晚正常供水。優理看著空水桶，室友拍拍它說：「那這個可以當垃圾桶了。」優理笑了一下，把水桶上的價格標籤撕掉。Yaze 早上在群組留的那句「先問房東水塔」還躺在訊息裡，他現在才真的看懂。

他把這件事折成一行小規則：停水前先問房東水塔，再決定水桶買幾個。這句話貼在租屋處的門後，跟雨傘掛在一起。明天如果又停水，他會先問，再跑五金行。

## 今天的小方法：停水前的三問
- 問水塔：先問房東或管委會，大樓有沒有儲水，停水會不會影響水龍頭。
- 問位置：找一個不會擋走道、也不會被當垃圾桶的位置放水桶。
- 問室友：先講好誰負責裝水、誰負責關水龍頭，免得停水當天大家同時洗澡。
