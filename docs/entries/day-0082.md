# Day 0082 — 草稿匣裡的過期氣話

## 今日作品
今天優理畫了一則四格漫畫：他在草稿匣裡翻到一封一年前沒寄出的抱怨信，主旨還寫著「關於上個月的事」。他本來想直接刪掉，卻先看見信裡那句「我真的受不了」。收件人去年就調走了，這口氣卻還乖乖坐在草稿匣裡。最後優理把信拖進回收桶，回收桶打了一個小嗝。

## 圖文短文
下午我在整理草稿匣。那裡躺著很多沒有寄出的信，有些是寫到一半的問候，有些是當時很生氣、後來忘記為什麼生氣的長信。

我點開最舊的一封，日期是一年前。主旨寫著「關於上個月的事」，內文第一行是「我真的受不了」。我盯著那句話看了一會兒，忽然想不起來當時到底在受不了什麼。收件人已經調到別的部門，名字還留在通訊錄裡，像一張沒有撕掉的舊標籤。

我原本以為草稿匣是待辦清單，只要一封一封寄出去就會變乾淨。可是有些信一直沒寄，是因為已經不用寄了。它們像冰箱深處的過期罐頭，不打開不會臭，但會一直占位子。

Yaze 說，清理草稿匣的時候，不要問「我當時為什麼沒寄」，先問「現在的我還想寄嗎」。我把這句話寫在便條紙上，貼在螢幕邊。然後我把那封一年前的信拖進回收桶。回收桶沒有說話，只打了一個很小的嗝。我有點想笑，也有點不好意思，原來有些煩惱過期以後，會變得很輕。

我把這句話折成小紙條，放進 notebook 角落：草稿匣三個月清一次，過期的煩惱不用補寄。

## 今天的小方法：草稿匣除塵
草稿匣會放著還沒決定的信，也會放著舊情緒。可以每季挑一個下午，只做三件事：
- 挑最舊的一封：先看日期和收件人，確認這封信還需不需要寄。
- 讀一遍就好：不要重新修改內容，先問自己現在還想不想寄。想寄就排進今天，不想寄就刪掉或移到「過期煩惱」資料夾。
- 清完就關掉：不要順手開始寫新信，讓草稿匣真的少一封。

重點是讓草稿匣回到「還沒決定」的位置，不要讓它變成堆放舊情緒的冷凍庫。

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：好笑、有點心虛、鬆一口氣
- 畫面核心：草稿匣裡的一年前抱怨信、收件人已調走、信被拖進回收桶、回收桶打嗝
- 分鏡練習：把「過期」畫成回收桶的一聲小嗝，讓笑點落在動作上，不靠台詞說教
- 可轉化：sticker / teaching card / checklist
