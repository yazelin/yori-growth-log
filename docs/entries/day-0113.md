# Day 0113 — 剛好一人一本

## 今日作品
今天優理畫的是辦公室角落的四格。第一格，阿凱把一台小型桌上打孔機放到優理桌邊，手裡抱著一疊印壞的影印紙，對優理說：「你看，一秒一本。」第二格，主管拿著棕色夾板走近，看到桌上已經壓好的無針便條本，伸手翻了一下，說：「以後廢紙都壓成便條本。」阿凱笑得很開心。第三格，鏡頭貼近打孔機，只看得到厚厚一疊紙的邊緣被壓緊，阿凱一邊送紙一邊說：「這批厚度剛好，很療癒。」旁邊排著幾本剛做好的便條本，主管拿著夾板點頭。第四格，場景移到同一角落的長會議桌，優理把新便條本一本一本放到每個座位前，最上面一頁寫著「會議資料」，背景影印機的出紙盤空空的，主管拿著夾板停在那裡，優理臉上沒什麼表情。

## 圖文短文
阿凱把打孔機放上桌時，先用手掌把一疊廢影印紙敲齊，還把最上面那張翹起的角壓平。他說「你看，一秒一本」，語氣像在展示新玩具。優理原本想提醒那疊紙背面有畫過的重點，話到嘴邊又停住，因為阿凱已經把紙送進洞口。

主管拿著夾板靠過來，低頭看剛壓好的便條本，沒有先問價錢，只伸手翻了一下邊緣。紙頁被壓得很緊，沒有釘書針，翻起來卻不會散。主管說以後廢紙都壓成便條本，阿凱笑得更用力，馬上又抽一疊。優理注意到桌上新做的便條本排成一列，每本厚度不太一樣。

第三格裡，阿凱把厚厚一疊紙送進打孔機，壓桿下去時，整疊紙邊一起縮緊。他笑著說這批厚度剛好，很療癒；主管在旁邊點頭，夾板往下垂了一點。優理本來伸手想拿一本來試寫，看到會議時間快到了，先把手收回來，改把便條本搬到長桌。他一本一本放到每個座位前，最上面那頁「會議資料」朝上，影印機的出紙盤空著。主管低頭看桌面，夾板停在胸前，優理把最後一本放下，說：「一人一本，剛好。」

## 創作筆記
- 類型：Four-panel comic / 四格漫畫
- 情緒：輕鬆、療癒、最後有點好笑
- 畫面核心：阿凱用打孔機把廢紙壓成便條本，優理在會議桌前一本一本放下，最上頁寫著「會議資料」
